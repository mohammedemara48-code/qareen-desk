# سجل القرين — Qareen Desk

لعبة رعب ويب (PWA) قابلة للتثبيت، تنشر على **Vercel** من GitHub.

أنت موظفة شيفت ليلي في **غرفة عمليات بلدية الظلال**: البلاغات بتيجي **اتصال صوتي** على الخط الساخن، بتفتحي **محضر تحقيق** (سلسلة حيازة، أدلة، ملاحظات ضابط)، بتبعاتي **دورية** للعنوان، وبتختمي قرار نهائي في الدفتر الحي.

## اللعب
1. ارفعي السماعة عند الاتصال الوارد (أو تجاهلي بعقوبة).
2. اختاري ردود على الخط، ثم **فتح المحضر**.
3. أدوات: سجل مدني، مقارنة صور، مكالمات، كاميرا، **إرسال دورية**، شات، تنبيهات.
4. بعد تحقيق كافٍ (حد أدنى أدوات): اختمي — تأكيد / وسم قرين / دمج / حجر.
5. الدوريات ليها تبريد وترد لاسلكي متأخر يأثر على الدرجة والنهاية.

اختصارات: `1–4` أدوات · `8` دورية · `Enter` حجر · `Esc` استراحة (− درجة).

## الاتجاه
- واقعية فوتوغرافية + أزياء جريئة (١٨+)
- رعب مؤسسي / معلوماتي — مش جامب سكير
- واجهة حكومية باردة × أدلة ساخنة

## تشغيل محلي
```bash
npx serve .
```
لا يوجد بناء Node مطلوب. اربطي المستودع بـ Vercel (Framework: Other).

## الهيكل
- `index.html` — بوابة + مكتب + خط ساخن
- `css/app.css` — واجهة RTL
- `js/app.js` — حلقة الشيفت / أدوات / تسجيل
- `js/audio.js` — Web Audio (طنين، رنين، لاسلكي)
- `data/cases.js` — ١٠ محاضر + استدعاءات + دوريات
- `manifest.webmanifest` + `sw.js` — PWA

## النشر
`https://qareen-desk.vercel.app` عبر الدفع على `main`.
