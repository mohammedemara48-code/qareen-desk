# سجل القرين — Qareen Desk

لعبة رعب ويب (PWA) قابلة للتثبيت على أندرويد وiPhone، ومناسبة للنشر على **Vercel** عبر GitHub.

أنت موظف شيفت ليلي على بوابة بلدية: **سجل الاستمرارية**. قراراتك في الأرشيف بتحدد مين يفضل «إنسان» ومين يتوسم كـ**قرين**.

## الاتجاه البصري
- واقعية فوتوغرافية عالية
- أزياء جريئة / محتوى للبالغين (18+)
- واجهة حكومية باردة تتناقض مع صور الملفات

## التشغيل المحلي
افتح المجلد بأي سيرفر ثابت، مثل:

```bash
npx serve .
```

أو اربط المستودع بـ Vercel (Framework Preset: Other).

## الهيكل
- `index.html` — بوابة الشيفت
- `css/` — ستايل الواجهة
- `js/` — منطق اللعب
- `data/` — قضايا الشيفت ٠
- `manifest.webmanifest` + `sw.js` — PWA

## الحالة
نموذج أولي: شيفت ٠ (قضايا تجريبية + قرارات لا تُرجع).
